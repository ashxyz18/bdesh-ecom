# Railway Build Fix Plan

## Problem
Railway build fails with:
```
/bin/sh: ./node_modules/.bin/prisma: not found
```

The `.dockerignore` excludes `Dockerfile` (line 30), preventing Railway from using the Dockerfile. Railway falls back to Nixpacks which cannot find the prisma binary.

## Steps

1. **Fix `.dockerignore`** - Remove `Dockerfile` from exclusion list so Railway can use it
   - Remove line 30: `Dockerfile`
   - Keep other exclusions as they're valid

2. **Verify `railway.toml`** - Ensure builder is set to `dockerfile`
   - Current config is correct: `builder = "dockerfile"`

3. **Commit and push** - Push changes to trigger new Railway build
   - The fixed `.dockerignore` will allow Railway to properly use the Dockerfile
   - Dockerfile already uses `npm exec -- prisma generate` which works correctly

4. **Set environment variables in Railway dashboard**
   - `NEXTAUTH_SECRET` - Generate a secure random string (not "...")
   - `OPENAI_API_KEY` - Set actual API key (not "sk-proj-...")
   - `NODE_ENV` - Should be "production" (currently "development" in provided vars)

## Verification
After pushing, monitor Railway build log to confirm it uses the Dockerfile and prisma generates successfully.
