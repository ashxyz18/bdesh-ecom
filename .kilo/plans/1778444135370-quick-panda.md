# Plan: Admin Template Upload Dashboard

## Current State

The project has:
- `lib/templates.ts` - Static `TEMPLATE_MANIFESTS` object requiring manual registration
- `lib/templates/registry.ts` - Simple registry with hardcoded templates
- API routes for stores, products, auth
- No admin dashboard
- No ZIP upload/extraction

The project CAN handle file operations via:
- Next.js API routes (file uploads via `formidable` or `busboy`)
- Node.js `fs` module for writing files
- Node.js `zlib` or `adm-zip` for extraction

**What needs to be built: Admin dashboard to upload ZIP and auto-register templates.**

- Generate manifest.json
- Register in dynamic template registry

- Replace static `TEMPLATE_MANIFESTS` object

### Upload Flow

```
ZIP File
  ↓
POST /api/admin/templates/upload (multipart)
  ↓
Server receives file → saves to temp
  ↓
Extract ZIP to temp directory
  ↓
Scan files → find index.html, css/, js/
  ↓
Generate template ID from folder name
  ↓
Move files to public/templates/{id}/
  ↓
Create manifest.json
  ↓
Register template in runtime registry
  ↓
Return success
```

### Auto-Detection (Minimal)

1. Look for `index.html` (entry point)
2. Look for `css/` folder → find main CSS file
3. Look for `js/` folder → find main JS file
4. Generate simple manifest with generic mappings

function generateManifest(files, templateId) {
  const htmlFiles = files.filter(f => f.endsWith('.html'));
  const cssFiles = files.filter(f => f.includes('/css/'));
  const jsFiles = files.filter(f => f.includes('/js/'));
  
  return {
    id: templateId,
    name: templateId,
    css: cssFiles[0] || 'style.css',
    js: jsFiles[0] || 'main.js',
    entryPoint: htmlFiles[0] || 'index.html',
    sections: {} // Basic empty sections for now
  };
}

### Concept
Instead of converting each template to React components, use a **generic TemplateWrapper** that:
1. Loads the template's original HTML
2. Applies the template's original CSS
3. Injects dynamic data via DOM manipulation
4. Adds React interactivity (cart, search, wishlist) on top

### Template Folder Structure
```
lib/templates/{template-id}/
├── template.html       # Original HTML (kept intact)
├── template.css        # Original CSS (kept intact)
├── manifest.json       # Template metadata + section mappings
└── sections.ts        # Maps HTML sections to data sources
```

## Section Mapping Types

| Type | How It Works |
|------|--------------|
| `text` | Sets `textContent` of element |
| `attribute` | Sets any attribute (src, href, etc.) |
| `class` | Toggles CSS classes |
| `products` | Renders product cards into element |
| `cart-count` | Updates with cart item count |
| `visibility` | Shows/hides based on data |

## TemplateWrapper Component

```tsx
// TemplateWrapper.tsx
interface TemplateWrapperProps {
  store: Store;
  products: Product[];
  html: string;
  cssUrl: string;
  manifest: TemplateManifest;
}

export function TemplateWrapper({ store, products, html, cssUrl, manifest }: TemplateWrapperProps) {
  const { addItem, count: cartCount } = useCart();
  const { showToast } = useToast();
  const containerRef = useRef<HTMLDivElement>(null);

  // 1. Load CSS
  useEffect(() => {
    loadCSS(cssUrl);
  }, [cssUrl]);

  // 2. Inject HTML
  useEffect(() => {
    if (containerRef.current) {
      containerRef.current.innerHTML = html;
      applySectionMappings(containerRef.current, manifest.sections, { store, products, cartCount });
      initializeInteractivity(manifest.interactivity, { addItem, showToast });
    }
  }, [html, manifest, store, products]);

  // 3. React to store changes
  useEffect(() => {
    if (containerRef.current) {
      applySectionMappings(containerRef.current, manifest.sections, { store, products, cartCount });
    }
  }, [store, products, cartCount]);

  return <div ref={containerRef} className="template-container" />;
}
```

## Data Injection Flow

```
1. Store page loads
       ↓
2. Fetch store + products from API
       ↓
3. Load template manifest (JSON config)
       ↓
4. Fetch template HTML (raw string)
       ↓
5. Render TemplateWrapper with:
   - Original HTML injected into DOM
   - Original CSS applied
   - Manifest mappings applied
   - React interactivity initialized
       ↓
6. User sees full template with all features working!
```

## Example: Importing New Template

1. **Download template** → Copy HTML/CSS to `lib/templates/fashion/`

2. **Create manifest.json**:
```json
{
  "id": "fashion",
  "name": "Fashion Store",
  "css": "style.css",
  "sections": {
    "logo": { "selector": ".logo", "attribute": "src", "source": "store.logo" },
    "hero": { "selector": ".hero", "attribute": "style", "source": "store.settings.heroImage" },
    "products": { "selector": ".products-grid", "type": "products" }
  }
}
```

3. **Register in registry**:
```typescript
export const templateRegistry = {
  koskii: loadTemplate('koskii'),
  fashion: loadTemplate('fashion'),
};
```

4. **Done!** Template is now importable.
