## Technical Notes

**Image Generation API Choice**:
- **Replicate** (recommended): Open-source models, pay-per-use, Stable Diffusion XL
- **Stability AI**: Official Stable Diffusion API
- **OpenAI DALL-E**: Higher quality but more expensive

**For Replicate integration**:
```typescript
// packages/ai/src/services/image.ts
export async function generateImage(request: GenerateImageRequest): Promise<GenerateImageResponse> {
  const apiKey = process.env.REPLICATE_API_KEY;
  const response = await fetch("https://api.replicate.com/v1/predictions", {
    method: "POST",
    headers: {
      "Authorization": `Token ${apiKey}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      version: "stability-ai/sdxl:latest",
      input: {
        prompt: request.prompt,
        negative_prompt: request.negativePrompt,
        width: request.width || 1024,
        height: request.height || 1024,
      },
    }),
  });
  // ... polling for result
}
```
