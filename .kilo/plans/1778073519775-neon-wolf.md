# Bdesh-Ecom Improvement Plan

## 1. Code Quality & Testing
- Add unit/integration tests using Jest + React Testing Library for components, API routes, and utilities
- Configure ESLint (root + per-package) with Next.js, TypeScript, and React rules; resolve existing lint errors
- Add Prettier config for consistent code formatting across the monorepo
- Set up GitHub Actions CI pipeline to run lint, type-check, and tests on PRs
- Replace dummy implementations (e.g., forgot password `setTimeout` in `frontend/web/app/login/page.tsx` with actual API integration)
- Add React error boundaries for graceful failure handling

## 2. Database & Prisma Optimizations
- Add indexes to Prisma schema for frequently queried fields:
  - `User`: `email`, `phone`
  - `Store`: `subdomain`, `ownerId`, `status`
  - `Product`: `storeId + status`, `featured`
  - `Order`: `storeId + status`, `customerId + status`
  - `CartItem`: `userId`, `sessionId`
- Add Zod validation schemas for JSON fields (theme, settings, attributes, config) to ensure data consistency
- Add periodic cleanup job for expired sessions
- Add soft delete support for `Product`, `Store` models if required

## 8. Website Builder Generalization (Support Any Website Type)

- Rename `Store` model to `Site` with `websiteType` enum: ECOMMERCE, PORTFOLIO, BLOG, CORPORATE, RESTAURANT, EDUCATION, LANDING, NONPROFIT, REAL_ESTATE
- Add `websiteType` field to `Template` model to filter templates by site type
- Make e-commerce specific relations (`products`, `orders`, `paymentGateway`) optional, only used when `websiteType` is ECOMMERCE
- Add generic `SitePage` model (replaces `Page` model) tied to `Site` instead of `Store`, with support for custom page types per website type
- Add `Section` model to store reusable page sections (hero, features, testimonials, etc.) linked to `SitePage`, with `sectionType` enum covering all supported website types

### Template System Enhancements
- Update `Template` API routes to filter by `websiteType` and `category`
- Add template validation for generic section types (not just e-commerce):

  - Restaurant: menu, hours, reservation
  - Education: courses, instructors, testimonials
- Add `websiteType`-specific template config fields (e.g., `portfolioPage`, `blogPostPage`, `servicesPage` in `buildTemplateConfig`)
- Update AI design service to generate `websiteType`-specific template configs without hardcoding e-commerce features

### Frontend Builder Generalization
