# E-Commerce Platform - Fresh Redesign Plan

## User's Vision

1. **Pre-built Templates** - Users choose from pre-built website templates during onboarding
2. **Template Selection** - Users pick a template, it connects to their store
3. **Dashboard Control** - From dashboard, users can:
   - Add/modify products
   - Edit store info (name, logo, theme)
   - Change template settings
   - View orders
4. **Live Storefront** - The selected template renders with user's actual data

### Phase 2: Template System Redesign

#### Remove:
- `frontend/web/lib/templates/koskii/` - Hardcoded ethnic wear
- `frontend/web/lib/templates/dynamic/` - Complex HTML loader

#### New Template System:

**Template stored in database** (Template model already exists):
- id, name, slug, description, thumbnail, config (JSON)

**Store page fetches template config by ID**:
```typescript
// app/store/[storeId]/page.tsx
const store = await fetch(`/api/stores/${storeId}`).then(r => r.json())
const templateConfig = await fetch(`/api/templates/${store.templateId}`).then(r => r.json())
// Render template with store data
```

**Template Config Structure**:
```json
{
  "id": "fashion-store",
  "name": "Fashion Store",
  "sections": [
    { "type": "hero", "selector": ".hero", "data": "store.settings.hero" },
    { "type": "products", "selector": ".products-grid", "source": "api" },
    { "type": "footer", "selector": ".footer", "data": "store.settings.footer" }
  ],
  "styles": ["/templates/fashion-store/styles.css"],
  "script": "/templates/fashion-store/script.js"
}
```
